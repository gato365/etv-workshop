Before you arrive

Installs take 10–15 minutes and eat the hour if done live. Please finish these first. Full details are in file 01.

Pre-workshop checklist
  1. Install R 4.2 or newer from cloud.r-project.org (or with rig). Positron does not include R.
  2. Install Positron from positron.posit.co.
  3. Open Positron once and confirm the interpreter selector (top-right) shows R 4.x.
  4. Run the package installs on the right in the Console. Say yes to prompts.
  5. Download the zip above, unzip it, and in Positron use File → Open Folder… on the etv-workshop folder.

Candy for the first correct prediction, the first fixed error, and the first plot.

Package installs (once per computer) 
# From CRAN
install.packages(c("readr", "dplyr", "ggplot2", "remotes"))

# htmltab was removed from CRAN on 2022-11-11,
# so it installs from the maintained GitHub fork:
remotes::install_github("htmltab/htmltab")

# Checkpoint: four TRUEs
c("readr", "dplyr", "ggplot2", "htmltab") %in%
  rownames(installed.packages())

Install once; load with library() at the top of every script. Verified against the htmltab GitHub README and CRAN on 2026-10-28.

If something breaks

The three failures that eat workshop time. Each file has a longer troubleshooting list.

cannot open file 'data/cafe_orders.csv'

Wrong working directory. Run getwd(); it should end in etv-workshop. Use File → Open Folder… on that folder, then restart R.

package 'htmltab' is not available

Expected: it isn't on CRAN. Use remotes::install_github("htmltab/htmltab"). If GitHub rate-limits the room, skip it and use top_films_backup.csv.

could not find function "read_csv"

The package is installed but not loaded this session. Run library(readr). Same fix for dplyr and ggplot2 functions.

htmltab: table not found / columns look wrong

Wikipedia changed the page. Try which = 1, or read the backup CSV; the column names match, so the rest of the code runs unchanged.
